# Azha Ain Sokhna — Island Villas Landing (Madaar)

Next.js 16.4.2 · React 19.3 · Tailwind 4 · Web3Forms · Static (○)

## قبل النشر
1. `lib/config.ts` — الرقم، الواتساب، مفتاح Web3Forms، AW-ID و labels، الدومين، صياغة الإفصاح، الوحدات والأسعار وخطة السداد (أي قيمة null بتظهر "تُعلن قريباً").
2. `public/images/` — استبدل الصور (نفس الأسماء): hero.jpg · lagoon.jpg · villa-1.jpg · gallery-1..6.jpg
3. `npm install && npm run build` ثم Vercel.

لإضافة نوع وحدة تاني: زوّد object في `units` — الكروت بتتقسم عمودين تلقائياً.
